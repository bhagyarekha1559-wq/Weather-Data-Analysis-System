# Weather Data Analysis System

## Project Overview
The Weather Data Analysis System is a Python-based project that cleans, analyzes, and visualizes weather data.

## Objectives
- Analyze temperature, humidity, and weather conditions.
- Identify missing values and duplicate records.
- Clean and preprocess the dataset.
- Convert temperature from Celsius to Fahrenheit.
- Visualize weather patterns using graphs.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib

## Dataset
The project uses `climate_code.csv`, containing Date, Temperature, Humidity, and Weather columns.

## Implementation
1. Load the dataset.
2. Check missing values and duplicates.
3. Handle missing values and remove duplicate records.
4. Convert dates and sort the dataset.
5. Convert Celsius temperatures to Fahrenheit.
6. Generate graphs for data analysis.

## Results
The project presents weather data analysis through summary statistics and visualizations. Refer to the notebook for actual outputs and observations.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `climate_code.csv` if required.
3. Run the notebook cells in order.
4. Review the generated outputs and graphs.

## Conclusion
This project demonstrates how Python libraries can be used to clean, analyze, and visualize weather data.
